# ORVIA Foundation — reduced in-development build

This revision deliberately reduces the public promise while ORVIA Foundation is still being developed.

## What changed

- Added the wider ORVIA Oversight estate bar, master header navigation, customer-access route and main ORVIA footer/trust framework.
- Added ORVIA Oversight contact details, Companies House 16123685, ICO ZC152311, Armed Forces Covenant, ERS Bronze, veteran-founded and Trust A Veteran trust references.
- Reduced the public site from 15 routes to 8 current routes.
- Removed formal Apply, Access Fund, Partners, Impact, Community, Learning and Governance programme pages from public navigation.
- Added temporary redirects from those previous concept routes to the smaller current site.
- Made Foundation status explicit: **IN DEVELOPMENT**.
- Removed public donation, grant and open support-application expectations at this stage.
- Kept only the things that are genuinely useful now: the Foundation purpose, veteran/Service-family direction, free resources, About and essential legal pages.
