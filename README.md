# ORVIA Foundation website

Deploy-ready static website built from the ORVIA Foundation Golden Master brief.

## Included
- 15 public routes
- Warm ORVIA-aligned design system
- Access, veterans, learning, community, resources, apply, partners, impact, governance and legal pages
- Minimal initial support-request route that opens the user's email client
- Four free downloadable launch resources
- robots.txt and sitemap.xml
- Vercel static configuration

## Legal/status treatment
The site deliberately presents ORVIA Foundation as a public-benefit programme operated by ORVIA Oversight Ltd and does not claim registered-charity status, trustees, Gift Aid or public donations.

## Deployment
Upload the contents of this folder to any static host, or deploy the folder as a Vercel project. The intended initial hostname is foundation.orvia.org.uk subject to DNS/domain approval.

## Important operational follow-up
The current application route uses a minimal email handoff and explicitly tells applicants not to send sensitive documents initially. Before presenting the Foundation as fully operational, connect the intake to the controlled IRIS workflow with a named human owner and formally approve governance, criteria and funding.
